# Установка Li-m 0.9.0-rc.10

Windows 11 x64, установленный Python не требуется.

**Установщик:** закройте плеер и запустите `Li-m-0.9.0-rc.10-Setup.exe`.
Установка предназначена для текущего пользователя; по умолчанию каталог —
`%LOCALAPPDATA%\Programs\Li-m`. Автозапуск и ассоциации включаются отдельно
по выбору пользователя. Программа Windows по умолчанию автоматически не меняется.

**Portable:** распакуйте весь `Li-m-0.9.0-rc.10-portable.zip` в папку, доступную
для записи, и запустите `Li-m.exe`. Сохраняйте `_internal` рядом с EXE.
Профиль создаётся в `data` рядом с программой.

**Обновление:** создайте резервную копию через настройки плеера. Для обычной
версии используйте прежнюю папку установки. Для portable распакуйте новую
версию отдельно и перенесите собственную папку `data` после закрытия обеих копий.
Удаление программы сохраняет профиль и музыку.

Сборки этого предварительного выпуска не подписаны сертификатом издателя.
Сверяйте SHA256 файлов с SHA256SUMS.txt из того же выпуска.

## «Неизвестный издатель» и SmartScreen

У RC10 пока нет цифровой подписи издателя. Поэтому Windows может показывать
«Неизвестный издатель» или предупреждение SmartScreen. Публикация на GitHub
сама по себе не добавляет цифровую подпись.
[Пояснение Microsoft](https://learn.microsoft.com/en-us/windows/apps/package-and-deploy/smartscreen-reputation).

Скачивайте файлы из [официального выпуска](https://github.com/Lion-ls36/Li-m/releases/tag/v0.9.0-rc.10).
В нём есть SHA256SUMS.txt. При желании вычислите сумму скачанного установщика:

```powershell
Get-FileHash -LiteralPath '.\Li-m-0.9.0-rc.10-Setup.exe' -Algorithm SHA256
```

Сумма должна совпасть с записью для этого файла. SHA256 подтверждает совпадение
байтов, но не личность издателя. Отдельные политики Windows могут блокировать
неподписанные приложения.

## Если возникла проблема

[Сообщить об ошибке](https://github.com/Lion-ls36/Li-m/issues/new/choose) или
[прочитать порядок обращения](SUPPORT.md). Не прикладывайте музыку, базу
медиатеки или личные пути. Отчёты не отправляются автоматически.

Для установки рядом с другой копией используйте отдельную папку. Параметр
/NOICONS в текущем установщике не гарантирует пропуск ярлыка меню «Пуск»;
не полагайтесь на него для сохранения ярлыков другой копии.
