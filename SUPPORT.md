# Обратная связь Li-m

RC10 — публичный предварительный выпуск для Windows 11 x64.
[Скачать официальный выпуск](https://github.com/Lion-ls36/Li-m/releases/tag/v0.9.0-rc.10).
Все функции плеера бесплатны; учётная запись для самого плеера не нужна.

## Сообщить об ошибке

Откройте [формы обратной связи](https://github.com/Lion-ls36/Li-m/issues/new/choose)
и выберите **«Сообщить об ошибке»**. Можно писать по-русски, по-английски или
по-казахски. Перед созданием сообщения посмотрите, не описана ли проблема
в [существующих Issues](https://github.com/Lion-ls36/Li-m/issues).

Укажите версию, Setup или portable, Windows, действия для повторения и результат.
Для проблем со звуком полезны формат файла и тип выхода; для интерфейса — язык,
тема и масштаб экрана. Если Windows показывает конкретное название обнаружения
антивируса, приведите его текст отдельно от предупреждения о неизвестном издателе.

GitHub Issues публичны. Не прикладывайте музыку, базу медиатеки, резервную копию
профиля, пароли или коды входа. В снимках и текстах скрывайте личные пути и данные.
Плеер сам не загружает отчёты; публикация сообщения выполняется вами на GitHub.

## Поделиться результатом проверки

В тех же формах выберите **«Результат проверки»**. Нужны как успешные результаты,
так и обнаруженные проблемы. Отмечайте только выполненные сценарии и отдельно
указывайте оставшиеся непроверенными.

Для проверки USB/Bluetooth используйте отдельную portable-копию и небольшую
громкость. После отключения выхода ожидается пауза с сохранённой позицией;
после подключения звук возобновляется по команде Play. При настоящем сне Windows
ожидается пауза, после пробуждения — продолжение по команде Play.
Сон переводится вручную после сохранения вашей работы.

Для проверки диктора укажите его название, язык и конкретные проверенные элементы:
выбор треков, кнопки, настройки, перемотка, громкость и мини-плеер.
Работа программного теста доступных имён не заменяет прослушивание диктора.

Полученное сообщение — пользовательский отчёт. Оно не переводит автоматически
все сценарии или выпуск 1.0 в состояние «проверено».
