# Сторонние компоненты

Li-m использует Qt/PySide6/Shiboken 6.10.3, FFmpeg n7.1.3, Python 3.14.2,
NumPy 2.4.6, SciPy 1.17.1, TinyTag 2.2.1 и их встроенные компоненты.
Полные тексты лицензий/уведомлений находятся в `licenses/` дистрибутива.

Вместе с выпуском предоставляется `Li-m-0.9.0-rc.10-third-party-materials.zip`:
21 исходный архив и рецепты поставщиков, 395 файлов лицензий/уведомлений,
происхождение 186 сторонних исполняемых файлов, SHA256 каждого материала.
Исходный код самого Li-m в этот комплект не входит.
